# 🛒 Amazon Clone

A simple **Amazon Clone UI** built using **HTML** and **CSS**. This project replicates the look and feel of Amazon’s homepage to practice front-end development skills.

## 🚀 Features

* Responsive Amazon-style homepage layout
* Navigation bar with logo, search bar, and account/cart section
* Product grid showcasing items
* Footer with useful links

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**

## 🎯 Learning Outcomes

* Practiced HTML structure and semantic tags
* Improved CSS styling and layout design
* Hands-on experience replicating a real-world UI

## 📂 How to Use

1. Clone this repo:

   ```bash
   git clone https://github.com/Vinay-techdev/Amazon-Clone
   ```
2. Open `index.html` in your browser.
